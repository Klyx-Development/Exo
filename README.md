# About

Exo is an API that allows you to spawn client-sided entities using packets in Paper, this API makes it really easy to work with packet entities, by giving you a more object-oriented approach to working with them.
This library was heavily inspired by Tofaa's [EntityLib](https://github.com/Tofaa2/EntityLib), but it's not a fork of it, it is a different API, and doesn't rely on PacketEvents to function.
